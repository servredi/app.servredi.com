# SERVREDI MVP BUILD PROMPT (NEXT.JS VERSION)

We are building the MVP for a SaaS FSM (Field Service Management) platform called “ServRedi”.

Current marketing website:
https://www.servredi.com/

The MVP app will live at:
app.servredi.com

The product should feel modern, clean, mobile-first, fast, and similar in UX quality to modern FSM tools like:

* Jobber
* Housecall Pro
* ServiceTitan
* ClockShark
* FieldPulse

BUT simpler and cleaner for MVP.

The app MUST be:

* Mobile responsive
* Tablet responsive
* Desktop responsive
* Built for field technicians using mobile web browsers
* Built with scalability in mind
* Structured cleanly for future expansion

We are NOT building a throwaway prototype.
We are building a real production-ready MVP foundation.

---

# TECH STACK REQUIREMENTS

Frontend Framework:

* Next.js 15 using App Router
* TypeScript
* TailwindCSS
* shadcn/ui

Frontend Libraries:

* TanStack Query (React Query)
* Zustand for state management
* React Hook Form
* Zod validation
* Lucide React icons
* Recharts for reporting charts

Backend:

* Supabase
* PostgreSQL
* Supabase Auth
* Row Level Security (RLS)
* Realtime subscriptions where helpful

Hosting:

* Replit deployment initially
* Must be deployable later to Vercel
* Domain/subdomain ready

Architecture:

* Multi-tenant SaaS architecture
* Every company’s data must be isolated
* Clean scalable folder structure
* Modular architecture
* Reusable components
* Environment variables for secrets
* Mobile-first engineering approach
